# Fog of Drun

Мобильное приложение для прогулок и пробежек с механикой «Туман войны». Карта постепенно открывается по мере перемещения, а в скрытых тайлах генерируются сундуки, фото-задания и сокровища.

## Главный принцип

Приложение работает полностью офлайн на улице. Телефон выступает автономным накопителем данных. GPS работает без интернета, тайлы карты кэшируются заранее, весь прогресс хранится локально в SQLite. Синхронизация с ПК-сервером запускается вручную только дома по Wi-Fi.

## Стек

- React Native 0.85 + Expo 56
- TypeScript 6
- Leaflet JS 1.9 в WebView (вшит в HTML, 172 КБ)
- SQLite (expo-sqlite)
- Zustand (стор)
- expo-location, expo-file-system, expo-image-picker, expo-image-manipulator

## Основные механики

| Механика | Описание |
|---|---|
| Туман войны | Тайлы скрыты, открываются при входе GPS в радиус 100 м от тайла |
| Уровни и XP | За открытие тайлов, сундуки, сокровища. Бонусы за дальние районы и ночь |
| Сундуки | Спавнятся на новых тайлах, четыре редкости (common → legendary) |
| Bounding Box | Перед стартом пользователь выделяет зону прямоугольником или полигоном |
| Фото-задания | 3-5 точек внутри зоны. При подходе открывается камера, снимок сохраняется локально |
| Скрытые сокровища | Цель спрятана внутри круга радиусом 100-200 м со смещённым центром |
| Достижения | Система ачивок с отслеживанием прогресса |
| Сессии | Каждая прогулка — сессия с метриками: дистанция, площадь, найденные объекты |
| Синхронизация | Выгрузка треков, метрик и фотографий на ПК-сервер по HTTP |

## Модули

### Bounding Box
Пользователь выбирает рабочую зону на карте (прямоугольник или полигон).
Интерактивное рисование через WebView. Все интерактивные элементы (фото-задания, сокровища) генерируются только внутри этой зоны и только на скрытых туманом тайлах.

### Photo Tasks
На старте сессии внутри зоны генерируются 3-5 случайных точек с текстовым описанием. Когда GPS пользователя входит в радиус 100 м от точки, автоматически открывается камера. Снимок сохраняется в файловую систему, привязывается к тайлу в SQLite. На карте отображается иконка задания, при клике — фото в popup.

### Hidden Treasures
Целевая точка (Target X) генерируется внутри зоны. На карте отображается только круг радиусом 100-200 м со смещённым центром. Истинная цель гарантированно находится внутри круга (смещение ≤70% радиуса, случайный угол). При входе GPS в радиус 10 м от цели сокровище считается найденным.

### Session Analytics
При остановке сессии формируется сводка:
- дистанция (гаверсинусная сумма по треку)
- площадь исследованной местности (количество новых тайлов × площадь одного тайла)
- количество выполненных фото-заданий
- количество найденных сокровищ
- время сессии и XP

### PC Server Sync
Двухфазный протокол: сначала JSON-пакет (метаданные сессий, треки, метрики), затем multipart-загрузка фотографий. Флаг is_synced выставляется только после HTTP 200 OK от сервера. Сервер запускается на ПК в локальной сети (Flask/Express).

## Сборка APK

```fish
cd android && ./gradlew assembleRelease
```

APK: `android/app/build/outputs/apk/release/app-release.apk`

Установка:
```fish
adb install -r android/app/build/outputs/apk/release/app-release.apk
```

```
fogofdrun/
├── App.tsx                    # корневой навигатор (вкладки)

│   ├── store/useStore.ts      # глобальное состояние (Zustand)
│   ├── db/
│   │   ├── schema.ts          # SQLite схема + миграции
│   │   └── database.ts        # CRUD операции
│   ├── game/
│   │   ├── engine.ts          # основной цикл сессии
│   │   ├── fog.ts             # тайловая геометрия, гаверсинусы
│   │   ├── xp.ts              # XP, уровни, бонусы
│   │   ├── chests.ts          # сундуки
│   │   ├── achievements.ts    # достижения
│   │   ├── areas.ts           # BBox/полигон, отбор тайлов
│   │   ├── photoTasks.ts      # фото-задания, камера, файлы
│   │   ├── hiddenTreasures.ts # сокровища, офсет круга
│   │   └── analytics.ts       # метрики сессии
│   ├── map/
│   │   ├── mapHtml.ts         # Leaflet + туман + маркеры (1070 строк)
│   │   └── LeafletMap.tsx     # WebView bridge
│   ├── gps/tracker.ts         # обёртка expo-location
│   └── sync/
│       ├── syncClient.ts      # HTTP-клиент синхронизации
│       ├── packetBuilder.ts   # формирование JSON-пакета
│       └── syncConfig.ts      # адреса и таймауты
└── AGENTS.md                  # заметки для следующего разработчика
```

## Разработка

Запуск в разработке:
```fish
npx expo start
```

Типографика проверка:
```fish
npx tsc --noEmit
```

Сборка без интернета:
Gradle настроен на локальный дистрибутив, тайлы карты кэшируются при первой загрузке.
